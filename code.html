10 HTML Tags and Their Explanations

  1. <html> Tag

    The <html> tag is the root element of an HTML document. It contains all the other HTML elements on the page.

  2. <head> Tag

    The <head> tag contains information about the webpage, such as the title, styles, and metadata. This information is usually not displayed directly on the webpage.

  3. <title> Tag

    The <title> tag defines the title of the webpage. It appears in the browser tab.

  4. <body> Tag

    The <body> tag contains the visible content of a webpage, including text, images, links, and other elements.

  5. <h1> Tag

    The <h1> tag is used for the main heading of a webpage. It is normally the most important heading on the page.

  6. <p> Tag

    The <p> tag is used to create a paragraph of text.

  7. <a> Tag

    The <a> tag creates a hyperlink. It allows users to navigate to another webpage or location.

  8. <img> Tag

    The <img> tag is used to display an image on a webpage. It commonly uses the src attribute to specify the image location.

  9. <ul> Tag

    The <ul> tag creates an unordered list. Items in the list are normally displayed with bullet points.

  10. <br> Tag

    The <br> tag inserts a line break in the text. It is useful when you want to move content to a new line.

Conclusion

HTML tags are the basic building blocks of webpages. By learning these tags, beginners can start creating structured and useful webpages.
